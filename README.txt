PLAYLIST
--------
Paste a normal YouTube playlist URL and load it.

The YouTube API backend returns:
- title
- channel
- duration
- thumbnail
- video ID

YouTube Music itself is not embedded.
The YT MUSIC button opens the corresponding track in YouTube Music when possible.
